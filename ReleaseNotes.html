LithoGen.py
Release Notes

Release Date: December 31, 2024

Features

  • Use as an input an image and create an STL file for the output.

Known Issues

  • Latency when generating an STL file especially for high-resolution images.
  • Cannot directly use the STL file as it needs tweaking to be able to slice it with a 3D printing software.
  • Only support JPG/JPEG image formats.

Additional Information

As an example for tweaking the 3D file, use blender :

  • Drag and drop the STL file into blender.
  • Select the object.
  • Use the "Remesh" tool and change the voxel size as needed.

    Features

    Release Date: October 24, 2026

    Features

    • Added a desktop GUI (gui.py) with a live 3D preview, light position, opacity and rotation controls, and hover tooltips on the settings.
    • Reorganised the code into the lithogen package; LithoGen.py is now a thin command line entry point.
    • Added 3MF output next to STL. The extension of the output file picks the format, and 3MF files are much smaller.
    • Added tone-to-thickness curves (beer, linear, gamma).
    • Added image tuning: denoise, sharpen, contrast, brightness, gamma, auto-levelling, resampling filter, invert and mirror.
    • Plate size can be set by width, height or longest side in mm, with an adjustable sampling pitch.
    • Added a flat border for stiffness and framing.
    • Added curved plates (--curve-radius) with adjustable back segments.
    • Added a cut-out mode for logos and keychains that removes the background, by brightness or by colour.
    • Added a triangle budget that coarsens the pitch to keep the file size in check.
    • Added a manifold check on the exported mesh, a thickness map preview, and a dry-run mode.
    • Added support for many input image formats (jpg, png, bmp, tiff, webp, ...).

    Additional Information

    Requires Python 3.9 or newer. The GUI needs PyQt5 and vtk, and --preview needs matplotlib. Use --help to list every command line option.
